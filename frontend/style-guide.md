# Front-end Style Guide

## Layout

The designs were created at the following widths:

- Mobile: 390px
- Desktop: 1280px

> 💡 These are just the design sizes. Make sure your page works at every width, from small phones (320px) up to large screens.

## Colors

### Primary

- Ember Orange: #C2410C

### Neutral

- Off White: #F5F5F4
- Light Gray: #E7E5E4
- Line Gray: #D6D3D1
- Medium Gray: #78716C
- Dark Gray: #57534E
- Charcoal: #1C1917

> 💡 Every one of these colors is already in Tailwind's default color palette. Find the matching names in the Tailwind docs.

## Typography

### Body Copy

- Font size (paragraph): 16px

### Fonts

- Family: [Inter Tight](https://fonts.google.com/specimen/Inter+Tight)
- Weights: 400, 600, 900

- Family: [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif)
- Style: Italic

> 💡 Both fonts are already linked in `index.html`, and the Tailwind config there sets them up as `font-sans` and `font-serif`.

## Images

All food photos are in the `images/` folder. Each one is named after its item's `id` in the API.
